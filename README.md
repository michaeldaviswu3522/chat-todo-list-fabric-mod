## What This Mod Does

Chat ToDo List Fabric Mod provides a client-side task tracker for Minecraft Java running with Fabric. Rather than leaving the game to consult another application, players can use chat-based interactions to create, review, and manage their to-do items.

Its workflow is built around checklists and incremental task progress. List information is handled through local JSON editing, making it possible to organize objectives, multi-step activities, and recurring tasks within a Minecraft-focused setup.

## Main Capabilities

- Manage task lists directly through in-game chat
- Work through tasks using interactive, step-oriented checklists
- Edit task data in a local JSON list
- Run as a client-side Fabric mod
- Track objectives within Minecraft Java
- Keep to-do organization available inside chat
- Use a lightweight process for changing checklist entries
- Keep list management local instead of relying on server-side control

## Installation

1. Get the newest build using the project link above.
2. Copy the mod file into the Minecraft Java Fabric `mods` folder.
3. Launch the game with the Fabric profile that matches the build.
4. Enter chat and follow the mod's task workflow to add or modify entries.

When a release provides a JSON list file, store that file in the location required by the mod. This allows checklist changes to remain available across game sessions.
